# CrazyDucks

A fast-paced, 2D top-down survival shooter built entirely from scratch using C# and .NET WinForms.

### The Concept

You're armed, you're cornered, and you are being relentlessly chased by ducks. The premise is simple, but the gameplay is highly addictive: survive for as long as possible while racking up the highest score you can. Before dropping into the arena, you choose your starting weapon—Pistol, Rifle, or Sniper—each with its own firing mechanics and cooldowns. From there, it is a constant battle of kiting enemies around obstacles, managing your bullet cooldowns, and scrambling for randomly spawned ammo crates and medkits before you get overwhelmed.

### The Build & Technical Growth

Building a real-time, interactive game using WinForms—a framework traditionally used for desktop enterprise apps rather than games—was a fantastic technical challenge. Because I wasn't using a dedicated game engine like Unity or Godot, I had to build all the underlying mechanics from the ground up.

This project pushed me to deeply understand and implement core game development concepts in C#. I had to create a custom game loop to handle continuous rendering, build reliable collision detection for the player, walls, bullets, and enemies, and manage dynamic states like progressive level difficulty, high-score tracking, and randomized item spawning.

---

##  Game Features

* **Custom Loadouts:** Choose between 3 different starting weapons (Pistol, Rifle, Sniper), each offering a different playstyle.
* **Dynamic Difficulty:** As you progress through levels, the challenge scales up to keep you on your toes.
* **Resource Management:** Ammo is finite. You have to balance shooting with navigating the map to collect random ammo drops and medkits.
* **Full Audio Integration:** Custom sounds for shooting, taking damage, and interacting with the world.
* **High Score Tracking:** Built-in tracking to save your best runs and keep you coming back to beat your record.
